# peakgravity

PeakGravity is an IDE I'm working on that you can connect to 
your favorite LLM gateway or provider, it works when 
you are away and you still want work to be done 

#features

>You can access it anywhere from your phone

>you can approve the work and give new instructions before it commits your work 

>you can shut it down or boot up anytime anywhere if you have internet connection any where in the world
